# 🎮 Jogo da Velha

Projeto de um Jogo da Velha desenvolvido em **C#** utilizando **Windows Forms (.NET Framework)**.

## 📌 Sobre o projeto

O projeto foi desenvolvido com o objetivo de praticar conceitos de programação orientada a objetos, lógica de programação e desenvolvimento de interfaces gráficas.

## ⚙️ Funcionalidades

- Alternância entre jogadores X e O
- Verificação de vitória
- Verificação de empate
- Sistema de pontuação
- Bloqueio do tabuleiro após o fim da partida
- Reinício da partida
- Botão para encerrar o jogo

## 🛠️ Tecnologias utilizadas

- C#
- Windows Forms
- .NET Framework
- Visual Studio

## 🎯 Objetivo

Projeto desenvolvido para fins acadêmicos e de aprendizado, colocando em prática conceitos de programação e desenvolvimento de aplicações desktop.
